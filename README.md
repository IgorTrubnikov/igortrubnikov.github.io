# SOHA Coffee & Tea

Static mobile-friendly bilingual website. Open `index.html` or upload all files and folders to a GitHub Pages repository.

- Edit drink names, prices and image paths in `menu-data.js`. Prices are in thousands of VND.
- Replace photos in `assets/drinks/` and `assets/toppings/`.
- Replace logo in `assets/logo/`.
- Edit links and phone in `index.html`.

Note: Google Maps uses a search link based on the address from the photographed menu; verify the exact business pin. Zalo link uses the number on the menu; verify it belongs to the correct Zalo account.
